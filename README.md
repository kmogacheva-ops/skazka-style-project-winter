# Новогодняя ярмарка — Style Project

Статический сайт предложения парка «Сказка».

Сайт: https://skazka-style-project-winter.kmogacheva.chatgpt.site/

## Запуск

Откройте `dist/index.html` в браузере. Сборка и установка зависимостей не требуются. Для публикации на статическом хостинге выберите папку `dist`.

## Состав

- `dist/index.html` — страница сайта.
- `dist/style.css` — оформление и адаптивная верстка.
- `dist/assets/` — изображения и шрифты.

Материалы перенесены из локального проекта, связанного с указанным сайтом. Исходные документы, переписка и локальные настройки не включены. Цены и условия на странице отражают предложение, а не актуальный публичный прайс.

Права на фотографии, логотипы и шрифты принадлежат соответствующим правообладателям; публикация репозитория не предоставляет отдельной лицензии на эти материалы.
